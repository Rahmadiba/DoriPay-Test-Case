📱 Doripay — Aplikasi PPOB (Payment Point Online Bank)
Tentang Aplikasi
Doripay adalah aplikasi web pembayaran digital (PPOB) yang memungkinkan pengguna membeli produk-produk digital seperti pulsa, paket data, token listrik, voucher game, dan membayar tagihan bulanan — semuanya dalam satu tempat.
Aplikasi ini dibangun dengan arsitektur modern:

Backend: Go (Golang) + Fiber Framework + PostgreSQL
Frontend: Svelte + Tailwind CSS
Provider: Terintegrasi dengan Digiflazz & OrderKuota (Orkut) sebagai penyedia produk H2H (Host-to-Host)
Pembayaran: Tripay (QRIS, Virtual Account, E-Wallet)
Bot WhatsApp: Terintegrasi untuk pencatatan keuangan (Buku Kas) dan bantuan transaksi
